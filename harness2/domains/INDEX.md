# JARVIS Google Harness² — Experience Library R Index

- **voice_and_hud**: 대표님 전용 성문(Voice Print, F0 Hz + 근접 에너지) 필터와 3.8초 침묵 경청 버퍼(speechPauseMs=3800)를 유지하여 말씀 도중 끊김과 외부 소음 오작동을 100% 차단한다.
- **chlgd_and_cicd**: PowerShell(.ps1) UTF-8 인코딩, Python(.py) PYTHONUTF8=1, Freeze-VerifiedRuntime.js 해시 무결성 검증을 통과하고 모든 오더와 규칙을 ceo-orders-log.jsonl 및 jarvis-plans-and-rules.json에 Append 기록한다.
- **antigravity_mcp_and_plan_hud**: Antigravity 2.0의 Artifact/Sidecar 아키텍처를 자비스에 이식하여, Plan이나 규칙 정리를 논의할 때 전용 UI HUD 문서 뷰어 창(📋 Plan & CHLGD 뷰어)을 띄우고 MCP 서버로 양방향 연동한다.
